# Everyday Sound Lab – Teach Me a Lesson

This is an original React/Next.js classroom adaptation inspired by [Everyday Sound Lab](https://github.com/teacherdotdev/everyday-sound-lab), an Apache-2.0-licensed project.

Reference repository copyright remains with its respective contributors. The reference project's source code, artwork, sound recordings and branding have not been copied into this implementation. The classroom activity has original interface code and uses browser-generated synthesised audio. These synthetic cues are not faithful real-world field recordings.

Includes three original sample environments, replayable listening prompts, scoring, a teacher scene builder (using an original palette of sounds), and browser-local preservation of custom scenes. Accessibility and educational suitability should be reviewed with classroom users before wider release.
